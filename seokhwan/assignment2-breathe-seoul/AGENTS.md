# 프로젝트: 숨쉬는 서울

## 만들 것 (목적)
서울 25개 구의 실시간 대기질을 보여 주고, 지금 산책·운동·환기를 해도 되는지 알려 주는 모바일 웹.
기획 상세는 PLANNING.md를 따른다.

## 포함할 내용
- 구 선택 (선택한 구는 localStorage에 기억)
- 통합대기환경 등급 기반 한 줄 판정
- 활동 가이드: 산책 / 운동 / 환기 / 마스크
- 오염물질 6종(PM10, PM2.5, O3, NO2, CO, SO2) 등급 표시
- 서울 전체 구 순위
- 측정 시각, 새로고침, 로딩·에러 상태

## 기술 스택
- React + Vite (JavaScript, TypeScript 쓰지 않음)
- 스타일은 Tailwind CSS v4만 사용
- API: 서울 열린데이터광장 RealtimeCityAir (fetch 사용, axios 등 추가 금지)
- 배포: Vercel (서버 함수 api/)

## 폴더 구조
- api/air.js            : Vercel 서버 함수. 서울 API를 중계하고 인증키를 숨긴다
- src/api               : 브라우저에서 /api/air 호출
- src/hooks             : 데이터 불러오기 상태 관리
- src/utils             : 등급 기준·활동 가이드 계산 (화면 코드와 분리)
- src/components        : 화면 단위 컴포넌트
- src/App.jsx           : 컴포넌트를 조립만 한다

## 작업 방식
- 코드를 수정하기 전에 계획부터 보여준다. 계획에는 만들 파일 이름과 순서를 포함한다. 승인 전에는 파일을 수정하지 않는다.
- 한 번에 하나의 기능만 구현한다.
- 애매한 부분은 구현 전에 질문한다. 추측해서 채우지 않는다.
- 작업이 끝나면 바뀐 파일 목록과 바꾼 이유를 설명한다.

## 규칙 (제약)
- 새 라이브러리를 설치하지 않는다. 필요하면 먼저 물어본다.
- 인증키는 SEOUL_API_KEY 환경 변수로만 읽고, api/ 서버 함수 밖에서 쓰지 않는다. VITE_ 접두사 금지.
- 키 하드코딩 금지. .env는 커밋하지 않고 .env.example만 커밋한다.
- 서울 API 호출은 api/air.js에서만 한다. 화면 코드는 /api/air만 부른다.
- 등급 기준은 환경부 대기환경기준을 따른다. 임의로 바꾸지 않는다.
- 값이 없거나 점검 중인 항목은 '정보없음'으로 표시하고 화면이 깨지지 않게 한다.

## 완료 조건
- npm run build, npm run lint, npm test가 통과한다.
- npm run dev에서 실제 API 데이터가 뜬다.
- 375px 모바일 너비에서 가로 스크롤이 생기지 않는다.
- Vercel 배포 후 https에서 데이터가 뜬다.
