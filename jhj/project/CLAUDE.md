# CLAUDE.md

## 프로젝트 제목

**한 칸 도트 공방** — 마인크래프트 양털로 그리는 16×16 도안과 블록 준비물표

## 만들 것 (목적)

마인크래프트에서 작은 캐릭터(예: 펭귄)를 양털로 짓기 전에 웹에서 도안을 먼저 그려 보고, 필요한 양털 개수를 색별로 바로 확인하는 한 페이지 웹 앱을 만든다.

- 한 칸 = 양털 블록 1개다. 도안을 칠하는 순간 준비물 수량이 정해진다.
- 대상 사용자는 작은 캐릭터나 픽셀아트를 짓는 플레이어다. 서바이벌 모드에서 양털을 색별로 모아야 하는 사람, 양털 색을 아직 잘 모르는 입문자도 포함한다.

## 포함할 내용

### 1. 도안 그리기
- 16×16 격자 1개.
- 시작 도안을 고를 수 있다: **빈 도안** / **펭귄 예시**.
- 양털 8색 중 하나를 고르고 칸을 클릭하면 그 색으로 칠한다.
- 지우개를 고르면 클릭한 칸을 비운다(`null`).
- 도안을 바꾸면 현재 그림을 새 도안으로 교체한다.

### 2. 준비물 세기
- 색별 양털 개수와 합계를 표로 보여 준다.
- 수량은 따로 저장하지 않고, 항상 `grid`에서 다시 계산한다(파생 값).
- 빈칸은 세지 않는다. 흰 칸을 파란색으로 바꾸면 흰색 −1, 파란색 +1이 된다.

### 3. 이어서 만들기
- 저장 버튼을 누르면 현재 도안 1개를 localStorage에 저장한다.
- 앱을 다시 열면 마지막으로 저장한 도안부터 이어서 그린다.
- 저장값이 깨졌거나 형식이 맞지 않으면 빈 도안으로 시작한다.

### 4. 양털 텍스처 (mc-api)
- 키 없이 쓰는 mc-api에서 양털 8종의 텍스처를 불러온다. 팔레트와 도안은 같은 이미지를 쓴다.
- 이미지 로딩에 실패한 칸은 해당 양털의 대체 단색으로 칠해서 편집을 계속할 수 있게 한다.

#### API 정보 (2026-11-21 호출 확인)
- 기본 URL: `https://mc-api.bisai.dev`
- 블록 목록: `GET /v1/assets/blocks`
  - 응답: `{ version, block_count, exported_at, blocks: [{ id, name, icon, textures, kind, ... }] }`
  - 블록 약 1,277개, 응답 약 1.3MB → **앱 시작 시 1회만 호출**한다.
  - `blue_carpet`, `blue_wool_slab`처럼 양털 텍스처를 쓰는 다른 블록이 섞여 있다. `id`를 반드시 `===`로 비교한다(`includes('wool')` 금지).
- 텍스처: `GET /v1/assets/textures/{path}`, `{path}` = 블록의 `icon` 값(예: `block/white_wool.png`). 16×16 PNG가 온다.
- CORS: `Access-Control-Allow-Origin: *`라서 브라우저에서 바로 호출한다. 프록시는 필요 없다.
- 한도: 키 없이 IP당 분당 200크레딧. 블록 목록 호출에는 크레딧이 들지 않는다.

### 5. 화면 구성 (한 페이지)
- **상단 바:** 서비스 이름, 도안 선택(빈 도안 / 펭귄 예시), 저장 버튼, 상태 문구(저장 완료, 텍스처 로딩 실패 등).
- **중앙:** 정사각형 16×16 격자.
- **오른쪽:** 색상 팔레트(양털 8색 + 지우개)와 준비물표.
- **모바일(`md` 768px 미만):** 상단 바 → 격자 → 팔레트 → 준비물표 순서로 세로 배치. 격자는 화면 너비에 맞춘다.

### 6. UI 디자인
- 텍스처는 `image-rendering: pixelated`로 확대해도 흐려지지 않게 한다.
- 칸 사이에 1px 연한 선을 넣고, 빈칸은 체크무늬로 표시해 흰 양털과 구분한다.
- 선택한 색(또는 지우개)에는 굵은 테두리(약 3px)와 한글 이름을 함께 보여 준다.
- 배경은 밝은 회색으로 하고, 강조색은 저장 버튼에만 쓴다. 나머지 색은 양털 텍스처에서만 나오게 한다.
- 본문은 읽기 쉬운 한글 글꼴(예: Pretendard)로 하고, 제목에만 픽셀 느낌 글꼴을 쓴다.
- 접근성: 각 칸은 `<button>`으로 만들고 `aria-label="3행 5열, 파란색 양털"` 형태로 이름을 붙인다. 색은 한글 이름으로도 구분할 수 있어야 한다.

## 기술 스택

- **React** (Vite, JavaScript/JSX)
- **Tailwind CSS** (`@tailwindcss/vite` 플러그인)
- 상태 관리: React 내장 기능(`useState`, `useMemo`, `useEffect`)만 쓴다. 외부 상태 라이브러리는 쓰지 않는다.
- 저장소: 브라우저 `localStorage`
- 배포: **Vercel**

## 작업 방식

다음 순서로 한 단계씩 진행하고, 각 단계가 끝날 때마다 앱이 실행되는지 확인한다.

1. **세팅:** Vite로 React 프로젝트를 만들고 Tailwind CSS를 설치한다.
2. **데이터:** `wools.js`에 양털 8종을 대체 단색만으로 정의한다. `patterns.js`에 빈 도안과 16×16 펭귄 예시를 만든다. 펭귄 예시는 검은색·흰색·주황색 등을 써서 직접 그린다.
3. **편집 + 수량:** API 없이 단색만으로 격자, 팔레트, 지우개, 준비물표를 완성한다.
4. **API 연결:** `useWoolTextures`로 블록 목록을 받아 텍스처를 입힌다. 이미지 `onError`에서 대체 단색으로 바꾼다.
5. **저장·복원:** 저장 버튼과 앱 시작 시 복원을 추가한다.
6. **반응형·접근성:** 모바일 배치, `aria-label`, 키보드 조작을 점검한다.
7. **빌드·배포:** `npm run build`로 빌드를 확인하고 Vercel에 배포한다.

작업할 때 지킬 것:
- 한 번에 한 기능만 바꾸고, 바꾼 뒤에는 무엇이 달라졌는지 짧게 설명한다.
- 새 패키지를 설치해야 하면 먼저 이유를 말하고 확인을 받는다.
- 설명과 커밋 메시지는 한국어로 쓴다.

## 규칙 (제약)

### 데이터 규칙
- 도안 `grid`는 **길이 256인 1차원 배열**이다. `index = row * 16 + col`.
- 칸의 값은 양털 ID 문자열(예: `'blue_wool'`) 또는 빈칸 `null`만 허용한다.
- 준비물 수량은 state로 두지 않는다. `useMemo(() => countMaterials(grid), [grid])`로 매번 계산한다.
- 칠하기는 불변 업데이트로 한다. 같은 칸에 같은 값이 들어오면 상태를 바꾸지 않는다.
  ```js
  const paint = (i) =>
    setGrid((g) => (g[i] === selected ? g : g.map((v, k) => (k === i ? selected : v))));
  ```
- 지우개는 `selected = null`로 처리해 같은 `paint` 함수를 쓴다.

### 저장 규칙
- localStorage 키: `dot-studio:v1`
- 저장 형식: `{ "version": 1, "grid": [...256개] }`
- 복원할 때 `JSON.parse` 오류, 길이가 256이 아닌 경우, 모르는 양털 ID가 있는 경우에는 빈 도안으로 시작한다. 앱이 깨지면 안 된다.
- 저장하는 도안은 1개뿐이다(덮어쓰기).

### API 규칙
- 블록 목록은 앱 시작 시 **한 번만** 호출한다. 칠할 때마다 호출하지 않는다.
- API 키, 프록시 서버, 백엔드를 만들지 않는다.
- API가 실패해도 편집과 수량 계산은 대체 단색으로 계속 동작해야 한다.

### 범위 제한 (만들지 않는 것)
- 격자 크기 변경, 드래그로 여러 칸 칠하기
- 도안 여러 개 관리, 공유, 내보내기
- 상자(64개) 단위 환산, 염료 계산
- 로그인, 서버 저장
- TypeScript 전환, 외부 UI·상태 관리 라이브러리 추가

### 스타일 규칙
- 스타일은 Tailwind 유틸리티 클래스로 작성한다. 전역 CSS에는 `pixelated`, 체크무늬 같은 공통 스타일만 둔다.
- 색상값을 컴포넌트 안에 직접 쓰지 않는다. 양털 색은 `wools.js`에서만 가져온다.
