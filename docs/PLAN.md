# 오늘의 하늘 — 프로젝트 기획서

## 기본 정보
- 프로젝트명: 오늘의 하늘 (Today Sky)
- 담당자: 이우빈 / 학번: 202014056
- 과제: AI 코딩 도구 활용 — 과제 2 (자유 기획)
- 기술 스택: React, Vite, JavaScript, Tailwind CSS
- 데이터: Open-Meteo Forecast API

## 1. 프로젝트 개요
도시별 날씨를 간결하게 조회하는 웹 서비스다. 날씨 숫자만 보여주는 대신 오늘 필요한 정보(체감온도, 강수 가능성, 옷차림)를 하나의 화면에서 읽을 수 있도록 만든다.

## 2. 문제 정의
일반적인 날씨 페이지는 정보가 많고, 필요한 수치가 화면 곳곳에 흩어져 있다. 사용자는 현재 날씨, 앞으로의 변화, 외출 시 옷차림을 빠르게 판단하고 싶다.

## 3. 목표 사용자 및 사용자 시나리오
- 통학·출근 전에 날씨를 확인하는 사람
- 다른 도시로 이동하기 전 현지 날씨가 궁금한 사람
- 사용 흐름: 도시 선택 → 현재 날씨 확인 → 시간별·주간 예보 확인 → 옷차림 참고

## 4. 핵심 기능 및 수용 기준
1. **도시 선택**: 국내 8개 도시를 클릭하면 해당 좌표로 날씨를 새로 조회한다. 마지막 선택 도시는 브라우저에 저장한다.
2. **현재 날씨**: 기온, 체감온도, 습도, 풍속, 강수량, 날씨 상태, 최고·최저기온을 표시한다.
3. **시간별 예보**: 현재 시간대부터 최대 12시간의 기온, 날씨, 강수확률을 스크롤 카드로 표시한다.
4. **7일 예보**: 일별 날씨, 강수확률, 최고·최저기온을 나열한다.
5. **옷차림 가이드**: 체감온도 구간에 따른 추천과 비 예보 시 우산 팁을 제공한다(참고 정보).
6. **예외 처리**: 로딩 표시, 응답 검증, 연결 실패 안내, 재시도를 제공한다.
7. **반응형**: 모바일 가로 스크롤, 데스크톱 2열 레이아웃을 적용한다.

## 5. Open API 설계
엔드포인트: `https://api.open-meteo.com/v1/forecast`

| 파라미터 | 목적 |
|---|---|
| `latitude`, `longitude` | 선택 도시의 좌표 |
| `current` | 현재 기온·체감온도·습도·풍속·강수량·날씨 코드·일주기 |
| `hourly` | 시간별 기온·강수확률·날씨 코드 |
| `daily` | 일별 최고/최저기온·강수확률·날씨 코드·일출·일몰 |
| `timezone=Asia/Seoul` | 한국 현지 시간 표시 |
| `forecast_days=7` | 7일 예보 |

API 공식 문서: https://open-meteo.com/en/docs

**중요:** Open-Meteo는 키 없이 이용 가능한 공개 기상 API이지만, 한국 공공데이터포털에서 발급하는 **정부 공공데이터 API와는 다르다**. 담당자가 공공 API를 국가·공공기관 제공 API로 한정한다면 API 변경이 필요하다.

## 6. 화면 구성 및 디자인
- 상단: 브랜드/서비스 소개
- 도시 선택: 가로 스크롤 도시 버튼
- 현재 날씨: 포인트 컬러의 큰 히어로 카드
- 옷차림 팁: 별도 안내 카드
- 상세 정보: 습도, 풍속, 강수량 3개 카드
- 시간별 및 7일 예보
- 하단: 출처와 예보 안내

디자인 키워드: 미니멀, 따뜻한 블루, 카드형 대시보드, 넉넉한 여백, 모바일 우선.

## 7. 시스템 구조
브라우저의 React 앱 → `useWeather` 훅 → `src/api/weather.js` → Open-Meteo 서버 → UI 렌더링.
서버·데이터베이스는 필요 없다. 사용자 도시 설정만 localStorage에 저장한다.

## 8. 제외 범위
- 회원가입, 로그인, 별도 DB, 알림·지도, GPS 위치추적, 위치검색 API

## 9. 완료 기준
- 8개 도시에서 날씨 조회가 가능하다.
- 카드/주간 예보가 API 응답에 따라 변한다.
- 로딩/오류/재시도가 작동한다.
- 테스트·빌드가 통과하고 모바일 화면이 깨지지 않는다.
- GitHub PR과 Vercel 배포 링크가 제출된다.
