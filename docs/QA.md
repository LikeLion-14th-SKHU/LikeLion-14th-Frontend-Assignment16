## 미검증 / 후속 필요
- `npm install`: 실행 환경의 `registry.npmjs.org` DNS 연결 불가로 설치하지 못함.
- `npm run build`: npm 패키지를 설치할 수 없어 실행하지 못함. **빌드 성공으로 표기하지 말 것.**
- 브라우저 렌더링/기기별 반응형: React 패키지 미설치로 직접 확인하지 못함.
- 실시간 API 응답: 제작 실행 환경에서 `api.open-meteo.com` 연결 불가. API 공식 문서와 요청 파라미터를 대조했으나 실시간 응답 확인은 미완료.
- Vercel 배포 및 GitHub PR: 사용자의 계정/저장소 정보 없으므로 미수행.

## 사용자가 직접 확인할 명령
```bash
npm install
npm test
npm run build
npm run dev
```

## 브라우저에서 확인할 시나리오
1. 첫 화면에 서울의 현재 날씨가 뜨는가?
2. 인천/부산/제주로 변경했을 때 정보가 갱신되는가?
3. 페이지 새로고침 후 마지막 선택 도시가 유지되는가?
4. 개발자 도구 Network 차단 시 오류 안내와 다시 시도 버튼이 나타나는가?
5. 모바일 폭 375px에서 도시 선택과 시간별 예보가 가로 스크롤 되는가?
6. 브라우저 Console에 오류가 없는가?
7. 실제 Vercel 배포 URL에서도 정상 요청이 되는가?
